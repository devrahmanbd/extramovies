# 30-day sprint — UGC + Brands vibe + Paid Traffic (2026-10-08 → 2026-11-06)

Operating principle: every domain is a serious business with its own
readers, voice, and value — never filler farms feeding a mothership.
UGC (member reviews, lists, profiles) is the content engine; brand vibe
(consistent identity, honest criticism) is the moat; paid traffic buys
time while organic compounds. Everything published passes the writer
pipeline (voice → SEO structure → humanizer); nothing ships that we
wouldn't sign our name to.

## Targets (honest ranges, not promises)

| Stream | Month-1 realistic | Stretch |
|---|---|---|
| Organic (new domain) | 300–1,500 visits (long-tails indexing) | 3,000 with a breakout |
| Parasites (all channels) | 500–2,000 referral visits | 5,000 with a ranking thread/video |
| Paid (FB ads) | Whatever budget buys (entertainment $0.05–0.30/engaged visit) | Scale winners only |
| Total | 1k–5k organic+referral + paid on top | 30k only with paid doing the heavy lifting |

North-star metric for month 1 is NOT traffic: it's **indexed quality URLs**
(Search Console) + **publishing cadence kept** + **cost per engaged visit**.

## Week 1 — Foundation (Days 1–7)

- [ ] GSC + Bing verified on money domain; sitemaps submitted; URL
  Inspection requested for /, /reviews, /movies, 3 reviews, 3 hubs
- [ ] Analytics with UTM convention live (`utm_source`: letterboxd, reddit,
  youtube, medium, quora, facebook, fb-ads; `utm_medium`: referral/social/cpc)
- [ ] Brand profiles completed everywhere (bio → domain link, matching
  handles/descriptions): Letterboxd, YouTube, Reddit (user + own subreddit),
  Medium/Substack, X, Facebook Group (not just Page), Instagram, Threads,
  Pinterest, TikTok, Bluesky, Tumblr
- [ ] Publish 2 reviews (unreviewed/obscure titles first — CSV P0)
- [ ] Mirror both to Letterboxd with lists; answer 3 Quora threads
- [ ] FB ads: one test campaign, 3 creatives (verdict hooks, never "watch
  free"), $5–10/day, landing on review pages (not homepage)

## Week 2 — Cadence (Days 8–14)

- [ ] Publish 2–3 reviews; each gets: Letterboxd mirror + YouTube Short
  (verdict-first 30–60s) + X/Threads post
- [ ] 1 Reddit discussion post (original write-up, participant rules respected)
- [ ] 1 Medium/Substack import (canonical home) + Pinterest pins
- [ ] FB ads: kill losers (CPEV 2× target), double the winner, test 2 new angles
- [ ] Friday metrics: indexed URLs, impressions (GSC), referral sessions by
  source, CPEV per ad set, member signups

## Week 3 — Double down (Days 15–21)

- [ ] Same publishing cadence; add 1 "vs" or ending-meaning angle post
  (CSV P0 long-tails) + YouTube Community post per video
- [ ] First press release (brand story, homepage link, no keyword anchors)
- [ ] about.me/linktr.ee foundation links, interlinked, entity-consistent
- [ ] FB ads: scale winner 2–3× budget ONLY if CPEV holds 3 days straight
- [ ] Friday metrics + first cohort check: do ad visitors sign up / read
  2+ pages? If bounce > 90%, fix landing (verdict above fold), not budget

## Week 4 — Consolidate (Days 22–30)

- [ ] Same cadence; refresh oldest review if new facts (streaming moves)
- [ ] AI-parasite brand defense pages (Perplexity/Qwen for "extramovies
  review" queries — pirate-SERP counterweight)
- [ ] Kill every channel/post with zero indexed-or-referral signal after 3
  weeks; reallocate that time to the top 2 channels
- [ ] Month report: indexed URLs, impressions curve, referral table, CPEV,
  signup count, what ranked (double down list), what didn't (kill list)

## Quality gates (every post, every domain)

- Writer pipeline pass (voice → SEO → humanizer); zero em-dash tolerance stands
- Excerpts duplicated nowhere; canonicals point home; no spun copies
- Parasite → money links: sparing, branded anchors, useful content only
- No expired-domain redirects, no paid placements, no link schemes — the
  toxicity lesson applies to every property we touch

## Multi-domain note

Satellites run this same sprint with their own voice and audience — that is
what makes them real businesses instead of a PBN with extra steps. The
merger runbook (`docs/domain-merger-runbook.md`) governs if/when they
combine: real readerships merge cleanly; filler never does.

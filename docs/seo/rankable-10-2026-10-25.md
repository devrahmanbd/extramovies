# 10 films we can realistically rank for, long-term (2026-10-25)

Question: which films' keywords can a near-zero-authority review site truly rank for and get visitors from.
Selected on two axes only: **verified demand** and **winnable SERP**. Nothing here is chosen on taste.

## Method and tools

| Tool | What it gave | Limit |
|---|---|---|
| GSC Search Analytics (`gsc_api.py query`) | 90 days of our real queries | 46 rows, **all brand/piracy variants, zero film queries** — we have no content visibility to mine yet |
| Google Trends (JSON API via browser session) | 12-month demand, geo IN + US, relative index | relative-only (each comparison scales to its own max = 100); no absolute volumes |
| SERP audit — 4 parallel agents, 51 queries | who ranks for `<film> ending explained` | `websearch` is a proxy, not a Google snapshot; direct Google SERP reads are blocked (`google.com/sorry`) |
| TMDB `discover` | candidate pool by language/votes | TMDB votes are Western-skewed; Indian regional films sit under 400 |
| Semrush | — | **unavailable**: `SEMRUSH_TOKEN` carries no API entitlement (`ERROR 120`) |

Demand is expressed as the term's peak relative to the anchor `Tumbbad`'s peak (100) in the same region, for
the groups that share that anchor. Exception: Grave of the Fireflies was measured in a group where it set the
scale itself, so its US figure is a mean-vs-anchor ratio, not a peak-relative one.

curves are flat-to-rising, not decaying). Each also supports the site's existing low-difficulty patterns:
`<film> ending explained` and `<film> ending meaning` (both P0/Low in `docs/seo/keywords-extramovies.csv`),
plus the `<film> review` row.

## Runners-up and the avoid list

- **Runners-up:** Magadheera (IN 0.47x anchor, steady; winnable), The Lunchbox (large US demand but declining),
  The Handmaiden / Pan's Labyrinth / Snowpiercer / The Host / The Witch (all winnable, untested demand in IN),
  Primer (US demand inflated by non-film meanings — do not trust the number).
- **Stretch (biggest prize, hardest fight):** Drishyam — the largest demand measured in both regions (~36x the
  anchor in IN) but the SERP is a disambiguation fight across three remakes, and GQ owns the sequel's explainer.
  Target only with the year locked into title and slug.
- **Avoid as targets (MAJOR/farm wall):** Kantara, Maharaja, Drishyam 2, Kalki 2898-AD, Arrival, Perfect Blue,
  The Platform.
- **Weak demand despite winnable SERPs:** Jai Bhim, Ustad Hotel, The Skin I Live In, The Invisible Guest.

## Sequencing (this is the gate, not a footnote)

Page one is impossible for a URL Google has not indexed: today 7 of 84 sitemap URLs are indexed, and the
90-day query export contains no film query at all. Order of operations: publish the review with a real
"Ending explained" section → internal links from `/reviews` and a category hub → sitemap → owner's manual
Request Indexing clicks (10/day, REQUEST INDEXING is refused for automation on this property) → then these
keywords can earn position. Expect weeks-to-months per wave.

## Caveats

- Demand numbers are **relative indices**, not volumes. Semrush API is unavailable; treat all figures as
  directional rankings within a region, never as search counts.
- SERP verdicts come from a proxy engine (no MAJOR explainer ≠ no MAJOR page in Google). Re-verify each
  finalist's live India-localised Google SERP before committing a writing slot.
- Trends keyword = film title; the long-tail query itself is too low-volume to chart. Film-level interest is
  the proxy for `<film> ending explained` demand.
